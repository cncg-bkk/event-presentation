# Cloud Native Bangkok: Cloud Native AI

Join us for an immersive tech session on the engineering and infrastructure behind modern AI systems. As AI applications transition from experimental projects to production environments, scaling and managing them require robust, Cloud Native architectures.

This meetup brings together developers, data engineers, platform engineers, and AI practitioners to explore real-world implementations. Learn how to optimize AI workloads on Kubernetes, implement AI Gateways for traffic management, and build scalable Agentic frameworks. Expect practical insights and direct engineering experiences to help you run production-ready AI.
